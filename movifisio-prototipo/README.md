# MoviFisio — Protótipo de Startup

Protótipo demonstrativo em HTML, CSS e JavaScript de uma plataforma de fisioterapia, prevenção e conexão com profissionais.

## Como abrir
Abra o arquivo `index.html` no navegador.

## GitHub Pages
O projeto já inclui `.github/workflows/pages.yml` para publicação automática.

1. Envie todos os arquivos para um repositório GitHub.
2. Vá em **Settings > Pages**.
3. Em **Source**, escolha **GitHub Actions**.
4. Faça push para a branch `main`.

## Aviso
Este é um protótipo educacional/demonstrativo. Não realiza diagnóstico, prescrição terapêutica ou atendimento em saúde.
